# N7 Meeting Follow-Up — rules for Claude sessions

## First move

Read `NEXT.md`. It names what to pick up. If it has no open item, say so and stop.

## Source of truth

The PRD Claude Doc (https://claude.ai/artifact/4jQyEmkGRx8SDcAYMijeJn) wins; `docs/prd-meeting-follow-up.md` is a dated snapshot. PRD decisions D-01 to D-06 are fixed. `docs/DECISIONS.md` (D-1, D-2, ...) records every call made while building; add a dated row for every new one, and never silently reverse a row marked confirmed by Shane.

## Architecture rules

- **Logic lives in `src/`**, pure CommonJS with no dependencies (it runs inside n8n Code nodes). Code nodes in `workflow.json` are thin glue generated by `scripts/build-workflow.js`. Never hand-edit `workflow.json`: change `src/`, `prompts/` or the build script, then `npm run build`.
- **`config` is the only account-specific node** (PRD D-05). Nothing else holds an id, address or domain of Shane's accounts. Its defaults live in `config/config.template.json`.
- **Never trust the model for anything that leaves the workflow.** Recipients, external/internal, the matched company and every id come from code. Model text is HTML-escaped in the note and checked before use.
- **Prompt changes bump the version** in `prompts/extract.md` (and `reduce.md`); the version is written to every ledger row.

## Safety rails (product requirements, tested)

- **Drafts only.** The Gmail node is Create draft. Never add a send, reply or forward node, an SMTP/email-send node, or an HTTP call to a `/send` endpoint. `test/workflow.test.js` fails if one appears. Never claim the credential "can't send": it can; the workflow just never asks it to.
- **One CRM write:** a Note (create, or update by id). No tasks, deal-stage changes, contacts or property writes. HubSpot calls are limited to search, the deal→company association read, and notes.
- **No email alerts.** Errors go to the `errors` sheet tab and an optional webhook.
- **The ledger holds ids, codes and numbers only** (`src/ledger.js` refuses anything else). No transcript text, names or emails in the sheet.
- **Spend:** daily call cap and per-file token ceiling checked before any model call.

## Honesty rules

- Never invent a number. Runtime and cost figures are either measured by a run you did (say which) or labelled "target, not measured". The PRD's "under 90 s" and "under $0.10" are targets.
- Fixture scores in `docs/EVAL.md` come from hand-written recorded responses unless the doc says a live model was run. Never present them as model accuracy.
- Fixtures are synthetic: invented people and companies, `.example` domains. Never put real names, companies, emails or transcripts in this repo.
- Tests never call a model or a live API. Never delete, skip or weaken a test to get green.

## Git

- Gate before every push: `npm run gate`.
- Never commit `.env*` except `.env.example` (variable names only), and never commit n8n credential exports.
- Keep the workflow inactive in `workflow.json` (`"active": false`). Shane turns the schedule on.
